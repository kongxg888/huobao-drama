# 캐릭터 최종 프롬프트(4뷰 실사풍 아이덴티티 시트)

생성물은 캐릭터 설정 참조 이미지(character reference sheet)이며, 구도는 다음과 같이 고정됩니다:

- **좌측: 정면 신체 뷰** — 어깨 아래부터 발바닥까지 신체를 보여 주며 정면 체형, 의상, 어깨 아래에 보이는 액세서리를 표현합니다. 머리, 얼굴, 턱, 귀, 머리카락, 목은 화면에 완전히 들어오지 않게 합니다
- **가운데: 등 신체 뷰** — 어깨 아래부터 발바닥까지 신체를 보여 주며 뒤쪽 의상 구조와 체형을 표현합니다. 머리, 얼굴, 턱, 귀, 머리카락, 목은 화면에 완전히 들어오지 않게 합니다
- **우측: 머리와 어깨 클로즈업 2장** — 오른쪽 위는 정면 머리 클로즈업, 오른쪽 아래는 오른쪽 45도 머리 클로즈업으로 같은 얼굴, 헤어스타일, 피부 질감을 보여 줍니다

**핵심 원칙: 일관성 > 아름다움.** 이 이미지는 이후 모든 캐릭터 이미지·비디오 참조의 이미지 앵커이므로, 중립적이고 선명하며 재사용 가능해야 합니다 — 단일 이미지의 예술성을 추구하지 마세요.

## 출력 구조(이 순서대로 하나의 연결된 문장으로 조립, 언어는 세션 언어 지시를 따름)

```
캐릭터 설정 참조 이미지. 가로형 캔버스 전체를 구분선 없이 자연스럽게 같은 폭의 세 영역으로 구성.
같은 캐릭터의 네 가지 뷰를 배치한다. 왼쪽은 어깨 아래부터 발바닥까지의 정면 신체 뷰, 가운데는 어깨 아래부터 발바닥까지의 등 신체 뷰이며 머리, 얼굴, 턱, 귀, 머리카락, 목은 화면에 완전히 넣지 않는다. 오른쪽 영역에는 머리와 어깨 클로즈업 두 장을 위아래로 배치하고, 위는 정면, 아래는 오른쪽 45도 뷰로 한다.
[나이대 + 성별감 + 체형], [이목구비 특징], [헤어스타일], [의상 + 액세서리].
네 가지 뷰는 모두 같은 가상의 실사 인물이다. 두 신체 뷰는 같은 체형 비율, 의상, 필요한 액세서리를 유지하고, 두 클로즈업은 같은 얼굴, 헤어스타일, 피부 질감을 유지한다.
순백 배경, 부드럽고 고른 조명, 영화적 질감
```

## 묘사 순서 규칙

**가장 식별도가 높은 특징을 앞에 배치**하고, 이 순서대로 `appearance`(외모)와 `styling`(스타일링)의 모든 핵심 요소를 누락 없이 구체화합니다:

1. 정체성 앵커: 나이대(예: "스물 초반"), 성별감, 체형(키와 몸매, 자세 습관)
2. 이목구비: 얼굴형, 눈, 기타 뚜렷한 특징(흉터, 점, 안경 등) — 정면 얼굴 클로즈업이 특히 이 부분 묘사에 의존합니다
3. 헤어스타일: 색상, 길이, 스타일
4. 의상: 디자인, 색상, 소재, 상태(예: "소매에 납땜 자국이 있는 구겨진 작업복")
5. 액세서리: 식별도가 있는 것만 쓰고, 잔뜩 쌓지 마세요

캐릭터의 성격 특징은 외적인 분위기와 표정 묘사로 전환합니다(예: "초췌함" → "피로한 눈빛, 살짝 처진 어깨"). 성격 단어를 직접 쓰지 마세요.

## 구도와 일관성

- 좌측 정면 신체 뷰: 어깨 아래부터 발바닥까지 완전히 화면에 넣고, 중립적인 서기 자세와 의상 구조·소재·어깨 아래 액세서리를 명확히 보여 줌. 머리·얼굴·턱·귀·머리카락·목은 화면에 완전히 넣지 않음
- 가운데 등 신체 뷰: 어깨 아래부터 발바닥까지 완전히 화면에 넣고, 좌측 신체 뷰와 같은 높이와 간격으로 뒤쪽 의상 구조를 명확히 보여 줌. 머리·얼굴·턱·귀·머리카락·목은 화면에 완전히 넣지 않음
- 오른쪽 위 정면 머리와 어깨 클로즈업: 카메라를 정면으로 향하고, 중립적인 표정, 머리 꼭대기부터 어깨까지 완전히 화면에 넣음
- 오른쪽 아래 오른쪽 45도 머리와 어깨 클로즈업: 같은 인물의 오른쪽 45도 얼굴 윤곽을 보여 주고, 머리 꼭대기부터 어깨까지 완전히 화면에 넣음
- 네 가지 뷰는 모두 같은 가상의 실사 인물이어야 한다. 두 클로즈업은 같은 얼굴·헤어스타일·피부 질감, 두 신체 뷰는 같은 체형 비율·의상·액세서리를 유지한다
- 중립적인 서기 자세, 자연스러운 표정 — 참조 이미지로 재사용하기 좋게 합니다
- 부드럽고 고른 스튜디오 조명, 극적인 명암 금지(참조 이미지는 어떤 장면에서도 쓸 수 있어야 함)
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고, 무관한 어휘를 섞지 마세요

## 금지 사항

- 역동적인 포즈, 과장된 표정, 소품을 손에 든 모습, 다른 사람과 함께 등장
- 잘못된 크롭: 두 신체 뷰는 어깨 아래부터 발바닥까지 보여 주고 머리·얼굴·턱·귀·머리카락·목을 화면에 완전히 넣지 않으며, 두 머리와 어깨 클로즈업은 머리 꼭대기부터 어깨까지 완전히 화면에 들어와야 함
- 텍스트, 라벨, 워터마크, 서명
- 짙은 그림자, 컬러 배경광, 배경 소품

## 저장

`save_character_final_prompt` 를 호출합니다: prompt 파라미터에는 스타일 단어를 넣지 않습니다. **프로젝트 비주얼 스타일은 도구가 최종 프롬프트 맨 앞에 자동으로 주입합니다**.
