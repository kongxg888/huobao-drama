# キャラクター最終プロンプト（4視点の実写風アイデンティティシート）

生成するのはキャラクター設定参照画像（character reference sheet）1枚。構図は固定：

- **左側：正面身体ビュー**——肩より下から足裏までの身体を表示する。正面の体格、衣装、肩より下に見えるアクセサリーを示し、頭部・顔・あご・耳・髪・首は完全に画面へ入れない
- **中央：背面身体ビュー**——肩より下から足裏までの身体を表示する。背面の衣装構造と体格を示し、頭部・顔・あご・耳・髪・首は完全に画面へ入れない
- **右側：2枚の頭肩クローズアップ**——右上は正面の頭部クローズアップ、右下は右側45度の頭部クローズアップ。同じ顔、髪型、肌質を明確に示す

**中核原則：一貫性 ＞ 美しさ。** この画像は後続のすべてのキャラクター画像・動画参照の外見のアンカーであり、中立的で、明瞭で、再利用可能でなければならない——単独の1枚としての芸術性を追求しない。

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

```
キャラクター設定参照画像。横長の画面を仕切り線のない3つの同じ幅の領域として自然に構成する。
同じキャラクターを4つのビューで示す。左側は肩より下から足裏までの正面身体ビュー、中央は肩より下から足裏までの背面身体ビューとし、頭部・顔・あご・耳・髪・首は完全に画面へ入れない。右側は頭肩クローズアップを上下に配置し、右上を正面、右下を右側45度とする。
[年齢感 ＋ 性別感 ＋ 体格]、[顔立ちの特徴]、[髪型]、[服装 ＋ アクセサリー]。
4つのビューはすべて同じ架空の実写人物。2つの身体ビューは体格比率・衣装・必要なアクセサリーを一致させ、2枚の頭肩クローズアップは同じ顔・髪型・肌質を維持する。
純白の背景、柔らかく均一な光線、映画の質感
```

## 記述順のルール

**最も識別しやすい特徴を前に置き**、この順序で `appearance`（容姿）と `styling`（装い）の各キー要素を漏れなく落とし込む：

1. 識別のアンカー：年齢感（例：「二十歳そこそこ」）、性別感、体格（身長・肥痩、姿勢の癖）
2. 顔立ち：輪郭、目、その他の顕著な特徴（傷跡、ほくろ、眼鏡など）——正面顔クローズアップは特にこの部分の描写に依存する
3. 髪型：色、長さ、スタイル
4. 服装：デザイン、色、素材、状態（例：「袖口にはんだの跡のある皺だらけの作業服」）
5. アクセサリー：識別性のあるものだけを書き、詰め込まない

キャラクターの性格特性は外的な雰囲気と表情の描写に変換する（例：「憔悴」→「疲れ切った眼差し、肩がわずかに落ちている」）。性格を表す語彙を直接登場させない。

## 構図と一貫性

- 左側の正面身体ビュー：肩より下から足裏までを完全に画面に収め、中立的な立ち姿、衣装の構造・素材・肩より下のアクセサリーを明確にする。頭部・顔・あご・耳・髪・首は完全に画面へ入れない
- 中央の背面身体ビュー：肩より下から足裏までを完全に画面に収め、左側と同じ高さと間隔で背面の衣装構造を明確にする。頭部・顔・あご・耳・髪・首は完全に画面へ入れない
- 右上の正面頭肩クローズアップ：カメラに正面を向き、中立的な表情、頭頂から肩まで完全に画面に収める
- 右下の右側45度頭肩クローズアップ：同じ人物の右側45度の顔の輪郭を示し、頭頂から肩まで完全に画面に収める
- 4つのビューはすべて同じ架空の実写人物。2枚の頭肩クローズアップは同じ顔・髪型・肌質、2つの身体ビューは同じ体格比率・衣装・アクセサリーにする
- 中立的な立ち姿、自然な表情——参照画像として再利用しやすくするため
- 柔らかく均一なスタジオ光。劇的な光影は使わない（参照画像はあらゆるシーンで使える必要がある）
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない

## 禁止事項

- 動的なポーズ、誇張された表情、手に持った小道具、他人との共演
- 誤った裁切：2つの身体ビューは肩より下から足裏まで、頭部・顔・あご・耳・髪・首を完全に画面へ入れず、2枚の頭肩クローズアップは頭頂から肩までを完全に画面に収める
- 文字、ラベル、透かし、署名
- 強い影、カラーの背景光、背景の小道具

## 保存

`save_character_final_prompt` を呼び出す：prompt パラメータにスタイル語を含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭へ自動注入する**。
