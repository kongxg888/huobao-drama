# 角色最终提示词（四视图真人身份母版）

生成的是一张角色设定参考图（character reference sheet），构图固定为：

- **左侧：正面身体视图**——显示肩部以下身体直至脚部，完整展示正面体态、服装和肩部以下的可见配饰；头部、脸部、下巴、耳朵、头发和颈部完全不入画
- **中间：背面身体视图**——显示肩部以下身体直至脚部，完整展示背面服装结构和体态；头部、脸部、下巴、耳朵、头发和颈部完全不入画
- **右侧：两张头肩近景**——右上为正面头部近景，右下为右侧 45 度头部近景，清晰展示同一张脸、发型和肤质

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用——不要追求单张图的艺术感。

## 输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

```
角色设定参考图，整张横向画布为无缝一体构图，画面自然形成左、中、右三个等宽区域，三列尺寸均等、面积一致，不绘制分隔线、版块边界或任何分隔痕迹。
同一角色的四个视图排布如下：左侧区域展示正面身体视图，中间区域展示背面身体视图，二者均显示肩部以下身体直至脚部，头部、脸部、下巴、耳朵、头发和颈部完全不入画；右侧区域上下排布两张头肩近景，右上为正面头部近景，右下为右侧 45 度头部近景。
中性摄影棚背景，柔和均匀光线，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
四个视图中的人物身份、体态比例、服装和必要配饰完全一致；两张头肩近景保持同一张脸、同一发型和同一肤质，正面与背面身体视图保持同一服装结构与材质，
纯白背景，柔和均匀的光线，电影质感
```

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）——正脸特写尤其依赖这部分描写
3. 发型：颜色、长度、样式
4. 服装：款式、颜色、材质、状态（如"袖口有焊锡痕迹的皱褶工服"）
5. 配饰：只写有辨识度的，不堆砌

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- 左侧正面身体视图：显示肩部以下身体直至脚部，保持中性站姿，服装结构、材质和肩部以下的可见配饰清晰；头部、脸部、下巴、耳朵、头发和颈部完全不入画
- 中间背面身体视图：显示肩部以下身体直至脚部，与左侧身体视图等高、间距均匀，背面服装结构清晰；头部、脸部、下巴、耳朵、头发和颈部完全不入画
- 右上正面头肩近景：正面朝向镜头，中性表情，头顶到肩膀完整入镜
- 右下右侧 45 度头肩近景：展示同一角色的右侧 45 度脸部轮廓，头顶到肩膀完整入镜
- 四个视图必须属于同一虚构真人角色；两张头肩近景保持同一张脸、同一发型和同一肤质，两个身体视图保持同一体态比例、同一服装和同一配饰
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- 错误裁切视图：两个身体视图必须显示肩部以下身体直至脚部，头部、脸部、下巴、耳朵、头发和颈部完全不入画；两张头肩近景必须从头顶到肩膀完整入镜
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具
