# 当前集文本文件导入设计

## 1. 目标

在剧集工作台的“原始内容”步骤增加“导入文本”入口，让用户可以为当前集选择一个本地文本文件，将文件内容载入编辑框，再手动保存到当前集。

本次只做当前集单文件导入，不根据文件名自动创建或切换剧集。用户可以在第 1 集页面导入 `第一集.md`，在第 2 集页面导入 `第二集.md`。

## 2. 当前实现约束

- 剧集原始内容保存在 episode 的 `content` 字段。
- 页面已经使用 `localRaw` 作为原始内容编辑缓冲区，并通过现有 `saveRaw` / `saveRawWithToast` 保存。
- 导入只改变编辑缓冲区，不直接调用后端保存接口。
- 现有桌面版和网页端都加载同一套前端页面，因此不增加 Electron IPC，也不增加后端接口、数据库字段或第三方依赖。

## 3. 方案选择

采用浏览器本地文件选择器：页面创建隐藏的 `input[type=file]`，限制选择一个 `.txt`、`.md` 或 `.markdown` 文件，使用浏览器 `File.text()` 读取 UTF-8 文本。

这个方案改动最小，同时适用于网页端和桌面 APP；文本内容在本机读取，不上传到服务器。Electron 原生文件对话框和后端上传都不纳入本次范围。

## 4. 用户流程

1. 用户进入某一集的“原始内容”步骤，点击右上角“导入文本”。
2. 系统打开本地文件选择器，只允许选择一个 `.txt`、`.md` 或 `.markdown` 文件。
3. 用户取消选择时不改变当前内容。
4. 选择成功后读取文件，移除 UTF-8 BOM，并把换行统一为 `\n`。
5. 如果文件为空，显示错误提示，不改变当前内容。
6. 如果编辑框已有未保存内容，先提示用户确认替换；用户取消时保留原内容。
7. 确认后把文本放入 `localRaw`，停留在“原始内容”步骤，在编辑框中供用户检查。
8. 导入成功只提示文件名和字数，不自动保存。
9. 用户点击现有“保存”按钮后，才调用当前集更新接口写入 `content` 字段。

## 5. 界面改动

在 `frontend/app/views/drama/episode.vue` 的 Step 0 原始内容工具栏中增加：

- “导入文本”按钮；
- 隐藏文件输入控件；
- 导入处理函数；
- 导入中/读取失败时的提示。

在四种语言文件中增加导入按钮、文件类型、覆盖确认、空文件、读取失败和成功提示文案。按钮只出现在原始内容步骤，不出现在 AI 改写、资产制作或视频制作步骤。

## 6. 错误与安全边界

- 依靠文件扩展名限制文件类型；即使系统文件选择器返回其他类型，处理函数仍再次校验扩展名。
- 文件读取失败时不清空当前编辑内容。
- 空文件不覆盖当前编辑内容。
- 未保存内容被替换前必须经过确认。
- 不自动保存、不自动改写、不自动创建剧集。
- 不解析 Markdown 章节标题，不从文件名推断集数；文件名只用于成功提示。

## 7. 验收标准

- 在当前集原始内容页面可以选择并读取 `.txt`、`.md`、`.markdown`。
- 导入后内容准确显示在原始内容编辑框中，中文换行正常。
- 导入不会自动写入数据库；刷新页面前未点击保存时，原有已保存内容仍保持不变。
- 点击保存后，重新刷新当前集可以看到导入内容。
- 取消选择、空文件、非法扩展名、读取异常和覆盖确认取消均不会破坏当前内容。
- AI 改写、素材提取、分镜拆解和现有媒体生成流程不受影响。
- 结构测试和前端生产构建通过。

## 8. 非本次范围

- 一次批量导入多个章节文件。
- 根据 `第01集.md`、`EP01.md` 等文件名自动匹配剧集。
- 自动创建缺少的剧集。
- 拖拽导入、剪贴板导入和云盘导入。
- GBK/GB18030 编码选择器。
- Markdown 渲染预览；当前预览就是原始内容编辑框。
